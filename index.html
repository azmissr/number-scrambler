🔐 Number Scrambler

Password-based reversible number anonymisation

How it works: This uses a keyed Feistel cipher (SHA-256 based, similar in spirit to NIST's FF1 format-preserving encryption) to transform your number into another number of the same length, deterministically, based on your password.

Same number + same password → same scrambled output, every time. Enter the scrambled number with the same password to get the original back. No data is sent anywhere — everything runs locally in your browser.

Important: if you forget the password, the number cannot be recovered. Use at least 4 digits for reliable results. Save this page to your home screen for quick access.
